# Contribuir

1. Crea una rama descriptiva.
2. No agregues scraping, credenciales de usuario, acceso root ni APIs privadas.
3. Añade tests para validación/procesamiento.
4. Ejecuta `./gradlew lint testDebugUnitTest assembleDebug`.
5. Abre un pull request explicando cambios, permisos Android y límites de la API oficial usada.
